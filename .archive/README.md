# Archive provenance

`sources/` contains the rendered article-body captures used to rebuild the published archive. The live archive inventory is `archive-list.json`; per-issue verification and hashes are in `manifest.json`. Consult the root README for the capture and conversion method and its limits.

`previous-local-2026-10-24/` preserves the previous local files without modification. They include rewritten summaries, incomplete copies, and drafts. They are historical evidence of the old context, not authoritative published text. Do not use them as voice examples.
